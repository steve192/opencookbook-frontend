# CookPal's own food icons

Produce that Fluent Emoji has no icon for, drawn for CookPal in the style of Fluent Emoji Flat: a 32 x 32 grid,
flat fills, no outlines, Fluent's palette. `scripts/shopping-icons.mjs` renders them with the Fluent icons; a name
here must not be a Fluent name, and the catalogue lists the same names in `catalogue-data/curation/own-icons.txt`.

Some start from a Fluent Emoji Flat icon (MIT, Microsoft Corporation) with new colours or parts:

| Icon | From |
|---|---|
| apricot, nectarine | peach |
| sour_cherries | cherries |
| quince | pear |
| yellow_bell_pepper, red_bell_pepper | bell pepper |
| parsnip, radish | carrot |
| zucchini | cucumber |
| broad_beans | pea pod |
| cauliflower | broccoli |
| chard, kale | leafy green |

The others are drawn from scratch: arugula, asparagus, beetroot, black_currant, black_salsify, blackberry,
brussels_sprouts, celeriac, celery, chinese_cabbage, damson, endive, fennel, gooseberry, green_beans, hazelnut,
iceberg_lettuce, kohlrabi, lambs_lettuce, leek, mirabelle, plum, pointed_cabbage, pumpkin, radicchio, raspberry,
red_cabbage, red_currant, rhubarb, savoy_cabbage, small_red_radish, spring_onion, swede, walnut, white_cabbage,
white_currant.
